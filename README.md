# Portfolio

## Instruction

1. install [Flutter](https://docs.flutter.dev/install)

    ```bash
    flutter --version
    ```

2. clone the [repo](https://github.com/niam0t/niam0t.github.io)

    ```bash
    git clone https://github.com/niam0t/niam0t.github.io.git
    ```

3. run `flutter run` from project root

    ```bash
    cd niam0t.github.io
    flutter run             # -d <platform> [chrome, linux, windows]
    ```
